# Política operativa preliminar

## Principios
1. CréditosPunta no debe operar con clientes reales hasta completar la revisión jurídica y regulatoria.
2. El Score Atlas es una herramienta de apoyo, no una decisión automática definitiva.
3. Toda tasa, comisión, gasto y seguro debe ser evaluado para el cálculo del costo financiero y los límites legales aplicables.
4. No se aceptarán datos sensibles innecesarios.
5. Toda modificación de una operación debe quedar auditada.
6. Los datos de demo deben estar claramente separados de producción.

## Flujo de crédito
Cliente → Solicitud → Validación → Score Atlas → Evaluación humana → Aprobación/Rechazo → Contrato → Desembolso → Cuotas → Pagos → Cobranza → Cierre.

## Límites iniciales de producto (propuesta)
- Monto: $4.000 a $12.000 UYU.
- Plazos: 3, 6, 9 y 12 meses.
- Sin refinanciaciones automáticas.
- Primer crédito sujeto a límite conservador.

Estos valores son parámetros de producto, no una autorización legal para operar.
