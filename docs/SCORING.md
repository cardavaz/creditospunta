# Score Atlas — versión demo

El score actual es un motor experimental para prototipado, no una política crediticia lista para producción.

## Variables
- ingreso mensual
- cuota estimada / ingreso
- antigüedad laboral
- historial de préstamos buenos
- historial de mora

## Rangos
- 750–900: riesgo bajo
- 600–749: riesgo medio
- 300–599: riesgo alto

## Antes de producción
Validar estadísticamente el modelo con una cartera suficiente, definir reglas de rechazo, excepciones y revisión humana, documentar variables y controles de sesgo/no discriminación, y revisar su uso conforme a la normativa uruguaya aplicable.
