# Seguridad y producción

Antes de usar datos reales:

- Configurar PostgreSQL gestionado y backups.
- Secretos únicamente mediante variables de entorno.
- Autenticación fuerte y MFA para administradores.
- Roles y permisos mínimos.
- Registro de auditoría para altas, cambios, aprobaciones, pagos y ajustes.
- Cifrado en tránsito y revisión de cifrado en reposo del proveedor.
- No almacenar contraseñas ni datos de tarjetas.
- Política de retención y eliminación de datos.
- Revisión de protección de datos personales y cumplimiento aplicable en Uruguay.
- Separar entornos demo, staging y producción.

El repositorio actual es un prototipo y no debe recibir información personal real.
